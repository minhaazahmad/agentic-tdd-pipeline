\# Agentic TDD Generation Pipeline



An agentic pipeline that analyzes large enterprise configuration/codebases and generates structured Technical Design Documents (TDDs) using deterministic source scanning, semantic Map-Reduce chunking, evidence retrieval, and LLM-based Architect, Critic, and Manager agents.



\## Project Preview



!\[Agentic TDD Pipeline Front Page](screenshots/front-page.png)



\## Overview



The pipeline converts large source code/configuration projects into standardized Technical Design Documents while maintaining source provenance through stable evidence IDs.
