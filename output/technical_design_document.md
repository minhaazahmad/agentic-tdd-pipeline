### 5.2 Responsibilities

- UI layer renders screens and handles user interactions. [EV-LIB-MAIN-DART-1-140-0]
- File picker allows users to browse and select local audio files. [EV-LIB-MAIN-DART-1-140-0]
- HTTP client performs network requests for downloading or uploading data. [EV-LIB-MAIN-DART-1-140-0]
- Audio engine streams and controls playback of audio tracks. [EV-LIB-MAIN-DART-1-140-0]
- Archive component extracts or creates compressed audio packages. [EV-LIB-MAIN-DART-1-140-0]
- Permission handler requests runtime permissions (e.g., storage). [EV-LIB-MAIN-DART-1-140-0]

### 5.3 Data Flow

1. User taps a button → FilePicker opens → selected file path returned to app. [EV-LIB-MAIN-DART-1-140-0]
2. App may issue an HTTP GET/POST using http client to a remote service. [EV-LIB-MAIN-DART-1-140-0]
3. Received data can be stored using path_provider and processed with archive. [EV-LIB-MAIN-DART-1-140-0]
4. Audio files are loaded into just_audio for playback with UI controls. [EV-LIB-MAIN-DART-1-140-0]
